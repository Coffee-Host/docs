<Callout title="什麼是 server.properties？">
`server.properties` 是 **Minecraft 伺服器最重要的設定檔**，控制伺服器的基本行為和遊戲規則。所有類型的 Minecraft 伺服器（Paper、Forge、Fabric 等）都會使用這個設定檔。
</Callout>

# 設定檔位置

`server.properties` 位於伺服器的**根目錄**（最外層資料夾）。

<Callout type="info" title="首次啟動">
如果您找不到這個檔案，請先啟動一次伺服器，它會自動生成。
</Callout>

# 修改設定檔

<Steps>
    <Step>

    ### 步驟一：關閉伺服器

    在修改 `server.properties` 之前，**建議先關閉伺服器**，以確保設定正確儲存。

    </Step>

    <Step>

    ### 步驟二：開啟設定檔

    1. 前往面板的「**檔案管理**」頁面
    2. 在**根目錄**找到 `server.properties` 檔案
    3. 點擊檔案開啟編輯器

    ![開啟設定檔](/images/practice/server-properties/open.png)

    </Step>

    <Step>

    ### 步驟三：修改設定

    根據需求修改相關設定（詳見下方設定說明）。

    **格式說明：**
    ```properties
    設定名稱=設定值
    ```

    ![修改設定](/images/practice/server-properties/edit.png)

    </Step>

    <Step>

    ### 步驟四：儲存並重啟

    儲存設定檔後，**重新啟動伺服器**以套用變更。

    </Step>

</Steps>

# 常用設定詳解

## 🌐 伺服器基礎設定

這些設定控制伺服器的基本資訊和連線方式。

| 設定名稱 | 預設值 | 說明 | 建議值 |
|----------|--------|------|--------|
| `motd` | A Minecraft Server | 伺服器列表顯示的描述 | 自訂歡迎訊息 |
| `max-players` | 20 | 最大玩家人數 | 根據記憶體調整 |
| `online-mode` | true | 正版驗證 | true（正版）/ false（盜版） |
| `white-list` | false | 白名單模式 | 私人伺服器設 true |
| `server-port` | 25565 | 伺服器端口 | 通常不需修改 |

### MOTD（伺服器描述）設定

MOTD 會顯示在 Minecraft 的伺服器列表中：

```properties
# 單行訊息
motd=歡迎來到我的伺服器！

# 雙行訊息（用 \n 換行）
motd=\u00A7b歡迎來到我的伺服器！\u00A7r\n\u00A7e正在運行 1.20.4
```

<Callout type="info" title="顏色代碼">
`\u00A7` 是顏色代碼的 Unicode 表示：
| 代碼 | 顏色 | 代碼 | 顏色 |
|------|------|------|------|
| `\u00A70` | 黑色 | `\u00A78` | 深灰 |
| `\u00A71` | 深藍 | `\u00A79` | 藍色 |
| `\u00A72` | 深綠 | `\u00A7a` | 綠色 |
| `\u00A73` | 深青 | `\u00A7b` | 青色 |
| `\u00A74` | 深紅 | `\u00A7c` | 紅色 |
| `\u00A75` | 紫色 | `\u00A7d` | 粉紅 |
| `\u00A76` | 金色 | `\u00A7e` | 黃色 |
| `\u00A77` | 灰色 | `\u00A7f` | 白色 |
| `\u00A7l` | **粗體** | `\u00A7r` | 重置 |
</Callout>

### 正版/盜版設定

```properties
# 正版伺服器（只允許已購買遊戲的玩家）
online-mode=true

# 盜版伺服器（允許未購買遊戲的玩家）
online-mode=false
```

<Callout type="warn" title="盜版伺服器注意">
如果設定 `online-mode=false`，強烈建議安裝 **AuthMe** 登入插件，否則任何人都可以冒充其他玩家！
</Callout>

## 🎮 遊戲規則設定

這些設定控制遊戲的玩法和規則。

| 設定名稱 | 預設值 | 說明 | 選項 |
|----------|--------|------|------|
| `gamemode` | survival | 預設遊戲模式 | survival/creative/adventure/spectator |
| `difficulty` | easy | 遊戲難度 | peaceful/easy/normal/hard |
| `hardcore` | false | 極限模式 | true/false |
| `pvp` | true | 允許 PvP | true/false |
| `allow-flight` | false | 允許飛行 | true/false |
| `spawn-protection` | 16 | 出生點保護範圍 | 0-999（格數） |

### 遊戲模式說明

| 模式 | 說明 | 適合伺服器類型 |
|------|------|----------------|
| `survival` | 生存模式，需要收集資源 | 生存服、RPG 服 |
| `creative` | 創造模式，無限資源 | 建築服、測試服 |
| `adventure` | 冒險模式，不能破壞方塊 | RPG 服、小遊戲服 |
| `spectator` | 旁觀模式，可以穿牆 | 直播、觀戰 |

### 常見設定範例

```properties
# 生存伺服器
gamemode=survival
difficulty=normal
pvp=true
hardcore=false

# 創造建築伺服器
gamemode=creative
difficulty=peaceful
pvp=false

# 極限生存伺服器
gamemode=survival
difficulty=hard
hardcore=true
```

### 飛行設定說明

```properties
# 預設：不允許飛行（飛行會被踢出）
allow-flight=false

# 如果安裝了飛行插件（如 EssentialsX 的 /fly），需要設定為 true
allow-flight=true
```

<Callout type="info">
`allow-flight=false` 是為了防止作弊。如果您的伺服器允許玩家飛行（VIP 功能等），請設定為 `true`。
</Callout>

## 🌍 世界設定

這些設定控制世界的生成和特性。

| 設定名稱 | 預設值 | 說明 |
|----------|--------|------|
| `level-name` | world | 世界資料夾名稱 |
| `level-seed` | （空白） | 世界種子碼 |
| `level-type` | minecraft:normal | 世界類型 |
| `generate-structures` | true | 生成結構 |
| `spawn-monsters` | true | 生成怪物 |
| `spawn-animals` | true | 生成動物 |
| `spawn-npcs` | true | 生成村民 |
| `allow-nether` | true | 允許地獄 |

### 世界類型選項

```properties
# 一般世界（預設）
level-type=minecraft\:normal

# 超平坦世界（適合創造/紅石測試）
level-type=minecraft\:flat

# 放大化世界（山更高、洞更深）
level-type=minecraft\:amplified

# 大型生態域（生態域更大）
level-type=minecraft\:large_biomes
```

### 使用特定種子碼

```properties
# 使用特定種子碼生成世界
level-seed=123456789
```

<Callout type="warn" title="注意">
`level-seed` 只在**生成新世界時**生效。如果世界已經生成，修改種子碼不會有任何效果。
</Callout>

## ⚡ 效能設定

這些設定會影響伺服器的效能和流暢度。

| 設定名稱 | 預設值 | 說明 | 建議值 |
|----------|--------|------|--------|
| `view-distance` | 10 | 視野距離（區塊） | 6-10 |
| `simulation-distance` | 10 | 實體模擬距離 | 6-10 |
| `max-tick-time` | 60000 | 最大 Tick 時間 | 60000 |

### 視野距離建議

| 伺服器規模 | 玩家數 | 建議 view-distance | 建議 simulation-distance |
|------------|--------|-------------------|-------------------------|
| 小型 | 1-10 人 | 10 | 10 |
| 中型 | 10-30 人 | 8 | 8 |
| 大型 | 30+ 人 | 6 | 6 |

<Callout type="warn">
降低視野距離可以**顯著提升效能**，但玩家能看到的範圍會變小。請根據實際情況調整。
</Callout>

## 🔒 安全性設定

| 設定名稱 | 預設值 | 說明 |
|----------|--------|------|
| `enable-command-block` | false | 啟用指令方塊 |
| `op-permission-level` | 4 | OP 權限等級 |
| `spawn-protection` | 16 | 出生點保護範圍 |

### OP 權限等級說明

| 等級 | 權限 |
|------|------|
| 1 | 繞過出生點保護 |
| 2 | 使用作弊指令、指令方塊 |
| 3 | 管理玩家（kick、ban、op） |
| 4 | 使用所有指令（stop、save） |

# 完整設定檔範例

## 一般生存伺服器

```properties
#Minecraft server properties
motd=\u00A7b我的生存伺服器\u00A7r\n\u00A7e歡迎加入！
max-players=30
online-mode=true
white-list=false

gamemode=survival
difficulty=normal
pvp=true
hardcore=false
allow-flight=false

level-name=world
generate-structures=true
spawn-monsters=true
spawn-animals=true

view-distance=10
simulation-distance=10
spawn-protection=16
```

## 創造建築伺服器

```properties
motd=\u00A7e創造建築伺服器\u00A7r\n\u00A7a自由發揮創意！
max-players=20
online-mode=true

gamemode=creative
difficulty=peaceful
pvp=false
allow-flight=true

level-type=minecraft\:flat
spawn-monsters=false
spawn-animals=false
spawn-protection=0
```

<Callout type="info">
修改設定後需要**重新啟動伺服器**才會生效。
</Callout>
