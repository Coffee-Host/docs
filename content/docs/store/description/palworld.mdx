歡迎了解我們的《幻獸帕魯》(Palworld) 伺服器產品特色。我們提供專為多人遊戲打造的高效能、高穩定度託管環境。

## 伺服器備份服務

《幻獸帕魯》的存檔極為珍貴，加購伺服器本地備份功能是保障您與好友心血的最佳方式。

<Callout type="info">
**專家建議**：強烈建議您利用控制面板設定「排程自動備份」。遊戲處於搶先體驗階段，偶爾會發生存檔異常或回溯的問題，擁有定期備份能讓您隨時輕鬆「回檔」，免除遺失資料的風險。
</Callout>

- 您可以在控制面板中手動執行備份。
- 您能隨時一鍵還原先前的狀態，或是將備份檔案下載回個人電腦中妥善保存。

## 額外端口 (Port) 加購

每台伺服器預設皆會分配一個主要連線端口。若您有特殊的進階需求，可以申請額外的端口。

* **適用情境**：若未來遊戲或特定模組（如需要額外資料傳輸或網頁服務的 API 插件）需要額外的連線通道，即可派上用場。
* **購買方式**：請前往客戶中心的「附加服務」頁面進行選購 UDP 端口。
* **端口管理**：您可以在控制面板的「端口管理」介面，靈活調整與切換您的主要端口設定。

<Callout type="warn">
**防護與流量注意事項**
1. **極端攻擊處置**：若您的伺服器遭遇長時間、超大規模的惡意攻擊，為確保整體機房網路以及其他顧客的權益，我們將不得不暫時阻斷您的伺服器連線。
2. **流量公平使用**：遊戲伺服器全面享有「無流量上限」之優惠。惟請您務必遵守公平使用原則；若系統判定存在惡意或大量轉發流量之違規情事，我們將會啟動必要的流量限制機制。
</Callout>
