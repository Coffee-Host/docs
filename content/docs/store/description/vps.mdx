Coffee Host 所提供的雲端主機產品，是與《一零三三網路資訊有限公司》攜手合作。

雲端主機擁有百分之百的作業系統控制權（Root 權限）與極高的自由度。不論您是想要架設個人部落格、企業官方網站，或是建立專屬的應用程式後端，這台 VPS 都能完美勝任。

## 伺服器備份服務

為防範系統操作錯誤或不可預期的資料遺失，我們強烈建議您啟用伺服器本地備份功能。
您只需登入控制面板，即可輕鬆執行手動備份或設定自動備份排程，並在需要時一鍵還原您的雲端主機狀態。

## 雲端主機使用注意事項

在享受高效能 VPS 服務的同時，請您務必詳閱並遵守以下規範，以維持良好的網路生態：

1. **DDoS 攻擊處置機制**：
   為了保護整體機房網路的順暢，若您的伺服器遭遇嚴重的 DDoS 攻擊，系統的安全防護機制將會自動介入，並**暫時封鎖該主機的外部連線長達 3 小時**。
2. **合作夥伴個資共用協議**：
   本 VPS 產品為我們與《[一零三三網路資訊有限公司](https://1033.tw/)》深度合作之服務。當您選購本產品並提交身分驗證文件時，我們將會把您的驗證資料同步提供予該企業進行雙重核對，敬請知悉。
3. **雙重服務條款約束**：
   使用本項雲端主機服務期間，除了必須絕對遵守 Coffee Host 的各項規範外，您也同時受到《[一零三三網路資訊有限公司](https://1033.tw/)》之[服務條款](/docs/legal/1033-tos)約束。請務必詳細閱讀以確保自身權益。

<Callout type="info">
